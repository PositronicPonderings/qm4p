# AI Disclosure

This repository follows the
[ai-disclosure convention](https://github.com/ggfevans/ai-disclosure) (version 0.1).

Every source file carries its own tag, next to its licence tag, so the
disclosure travels with code copied out of this repository:

```c
/* SPDX-License-Identifier: MIT-0 */
/* SPDX-AI-Disclosure: ai-generated */
/* SPDX-AI-Model: claude-opus-5-5 */
/* SPDX-AI-Provider: Anthropic */
```

The levels, from the W3C AI Content Disclosure vocabulary the convention uses:

| Level | Meaning |
|---|---|
| `none` | no AI involvement |
| `ai-assisted` | human-authored; AI edited, refined, or filled in |
| `ai-generated` | AI-generated with human prompting and review |
| `autonomous` | AI-generated without meaningful human oversight |

The tags describe how the code was produced. They say nothing about its
quality, and they credit no one: that's the point.
