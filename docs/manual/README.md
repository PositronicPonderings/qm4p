# The QG4P Manual

*QuickGraphics 4 Pico: graphics for the Raspberry Pi Pico 2 and small SPI screens, in the spirit of QuickBasic.*

QG4P is part of [QM4P](../../README.md), a family of small Pico libraries. This manual also covers its companion QA4P, the asset pack library, in [Asset packs](reference/assets.md).
