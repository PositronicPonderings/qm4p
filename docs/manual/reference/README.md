# 4. Reference

Every function, grouped by what it's for. Each entry has the same shape: what it does in a line, the syntax, the QuickBasic equivalent where there is one, an example with a picture of what it draws, the details, and where to look next. Every example is compiled, and run, as part of QG4P's tests.

|---|---|

| [Percentages](percentages.md) | every drawing function in percentages of the screen (or view) |
| [GET and PUT](blocks.md) | copying rectangles, and stamping them six ways |
| [Text](text.md) | fonts, markup, printing, alignment, measuring, the cursor, scrolling |
| [Images](images.md) | opening and drawing images: 1:1, scaled, fitted; exact colours |
| [Colour](colour.md) | the palette, named colours, RGB, palette changes, colour adjustment |
| [Asset packs](assets.md) | finding images, text and data by name in flash; several packs at once (the separate `qa4p` library) |
